| A59 | **Owner decision (Upstash free tier, 10k requests/day):** the billing engine wakes once every `BILLING_POLL_SECONDS` (60) instead of every second. Each wake-up bills, in ONE Lua call per live session, every minute that starts before the next wake-up plus `BILLING_LEAD_SECONDS` (15), so minute _n_ is still paid before it is served. Postgres gates the engine: with no open session it makes no Redis request. Measured: 1.00 Redis request per live session-minute (500 sessions × 10 min), 0 when idle, 2 per settlement, 2 per WebSocket connection (ticket). At that rate the free tier covers roughly 8,000 consultation-minutes a day after OTP and rate-limit traffic.
